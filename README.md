# Китика: посредник для TikTok LIVE

Нужен Node.js 18+ (nodejs.org, версия LTS).

1. Открой start.bat блокнотом и впиши свой ник вместо ТВОЙ_НИК.
2. ИИ для ответов. Один из вариантов:
   - Ollama: установи, выполни `ollama pull llama3.1`, больше ничего не нужно;
   - Claude: убери `rem` у строки с ANTHROPIC_API_KEY и вставь свой ключ.
   Без ИИ Китика отвечает шаблонами.
3. Запусти start.bat и не закрывай окно во время эфира.
4. Ссылка для TikTok LIVE Studio:
   https://ТВОЙ-НИК.github.io/НАЗВАНИЕ-РЕПО/?ws=ws://localhost:8080&clean=1&music=1

Подарки в окне пишутся как "Подарок: Rose от ...". Если подарок не засчитывается,
посмотри его имя в окне и скажи Claude, он поправит.
Ключ Claude не загружай на GitHub: start.bat остаётся только на твоём компьютере.
